## 1. Project Goals & Constraints

### What You Are Building

A **multi-tenant SaaS platform** called **FeedbackOS** where:

- Product teams create organizations (tenants)
- Customers submit feature requests on public/private boards
- Teams manage a public roadmap (Kanban/List/Timeline)
- Teams publish branded changelogs with scheduling and AI drafts
- Teams host a self-serve knowledge base with semantic search
- Teams build surveys/NPS forms with drag-and-drop
- AI clusters feedback, detects duplicates, and generates summaries

### Hard Constraints

- **Stack is fixed:** Laravel 11 + Inertia.js v2 + Vue 3 (Composition API) + PostgreSQL 16 + Redis 7
- **No separate frontend repo.** It is a monolith. Inertia bridges Laravel controllers to Vue pages.
- **All Eloquent models for tenant data must carry `org_id`** and use a global scope — never rely on manual `where('org_id')` in controllers.
- **Public developer API** lives in `routes/api.php` (Bearer token). Admin portal lives in `routes/web.php` (Inertia + cookie session).
- **AI calls are always queued** — never synchronous in HTTP requests (except streamed changelog draft).
- **All sensitive credentials** (integration tokens, webhook secrets) must be encrypted at rest using Laravel `Crypt`.

### Required Software Versions

```
PHP          >= 8.3
Composer     >= 2.7
Node.js      >= 20 LTS
npm          >= 10
PostgreSQL   >= 16   (with pgvector extension enabled)
Redis        >= 7
Meilisearch  >= 1.7
```

### Local Dev with Laravel Sail (Docker)

```bash
# 1. Install Laravel installer globally
composer global require laravel/installer

# 2. Create new project (do NOT use --starter-kit flag)
laravel new feedbackos

# 3. Enter project directory
cd feedbackos

# 4. Install Sail with required services
php artisan sail:install
# Select: pgsql, redis, meilisearch, mailpit

# 5. Start containers
./vendor/bin/sail up -d

# 6. Verify pgvector is available inside Postgres container
./vendor/bin/sail psql -U sail -c "CREATE EXTENSION IF NOT EXISTS vector;"
```

### pgvector Setup (Critical)

In the Sail `docker-compose.yml`, the default postgres image does NOT include pgvector. You must override it:

```yaml
# docker-compose.yml — replace the pgsql service image
pgsql:
  image: pgvector/pgvector:pg16
  environment:
    POSTGRES_DB: "${DB_DATABASE}"
    POSTGRES_USER: "${DB_USERNAME}"
    POSTGRES_PASSWORD: "${DB_PASSWORD}"
  volumes:
    - "sail-pgsql:/var/lib/postgresql/data"
```

Then enable the extension in a migration (see Section 6).

## 7. Multi-Tenancy Architecture

### 7.1 — BelongsToOrganization Trait

Create `app/Traits/BelongsToOrganization.php`. This trait must be applied to **every** model that belongs to an org.

```php
<?php

namespace App\Traits;

use App\Models\Organization;
use App\Scopes\OrganizationScope;

trait BelongsToOrganization
{
    protected static function bootBelongsToOrganization(): void
    {
        // Automatically add org_id to all new records
        static::creating(function ($model) {
            if (app()->has(Organization::class)) {
                $model->organization_id ??= app(Organization::class)->id;
            }
        });

        // Add global scope to all queries
        static::addGlobalScope(new OrganizationScope());
    }

    public function organization()
    {
        return $this->belongsTo(Organization::class);
    }
}
```

### 7.3 — ResolveOrganization Middleware

Create `app/Http/Middleware/ResolveOrganization.php`. This middleware must run on **every** request.

```php
<?php

namespace App\Http\Middleware;

use App\Models\Organization;
use App\Models\CustomDomain;
use Closure;
use Illuminate\Http\Request;
use Symfony\Component\HttpKernel\Exception\NotFoundHttpException;

class ResolveOrganization
{
    public function handle(Request $request, Closure $next)
    {
        $host = $request->getHost();
        $appDomain = parse_url(config('app.url'), PHP_URL_HOST);

        $org = null;

        // Strategy 1: Custom domain lookup
        if ($host !== $appDomain) {
            $customDomain = CustomDomain::where('domain', $host)
                ->whereNotNull('verified_at')
                ->first();
            if ($customDomain) {
                $org = $customDomain->organization;
            }
        }

        // Strategy 2: Subdomain (e.g. acme.feedbackos.app)
        if (!$org && str_ends_with($host, '.' . $appDomain)) {
            $slug = explode('.', $host)[0];
            $org = Organization::where('slug', $slug)->first();
        }

        // Strategy 3: Path prefix or query param (for dev/testing)
        if (!$org) {
            $slug = $request->header('X-Organization-Slug')
                ?? $request->query('org');
            if ($slug) {
                $org = Organization::where('slug', $slug)->first();
            }
        }

        if (!$org) {
            // For API routes, return 404. For web routes, show landing page.
            if ($request->expectsJson()) {
                throw new NotFoundHttpException('Organization not found.');
            }
            // Allow the request through to landing/marketing pages
            return $next($request);
        }

        // Bind organization into the container
        app()->instance(Organization::class, $org);
        $request->attributes->set('organization', $org);

        return $next($request);
    }
}
```

Register in `bootstrap/app.php`:

```php
->withMiddleware(function (Middleware $middleware) {
    $middleware->prepend(App\Http\Middleware\ResolveOrganization::class);
    $middleware->appendToGroup('web', [
        App\Http\Middleware\HandleInertiaRequests::class,
        App\Http\Middleware\SecurityHeaders::class,
    ]);
})
```

### 8.3 — Customer User SSO (Signed JWT)

In `SsoController@verify`:

1. Receive signed payload: `{userId, email, name, orgId, timestamp, signature}`
2. Verify HMAC-SHA256 signature using `WIDGET_HMAC_SECRET`
3. Reject if `timestamp` is older than 5 minutes
4. Upsert `CustomerUser` record in org scope
5. Issue a short-lived Sanctum token scoped to customer role
6. Return token to widget iframe via JSON

```php
// SsoTokenService.php
public function verify(array $payload): CustomerUser
{
    $expected = hash_hmac('sha256',
        $payload['userId'] . '|' . $payload['timestamp'],
        config('services.widget.hmac_secret')
    );
    if (!hash_equals($expected, $payload['signature'])) {
        throw new InvalidSsoTokenException();
    }
    if (now()->timestamp - $payload['timestamp'] > 300) {
        throw new ExpiredSsoTokenException();
    }
    return CustomerUser::updateOrCreate(
        ['organization_id' => app(Organization::class)->id, 'external_id' => $payload['userId']],
        ['email' => $payload['email'], 'name' => $payload['name']]
    );
}
```

```php
// PostVoteController@store (api.php route, returns JSON)
public function store(Request $request, Post $post): JsonResponse
{
    $direction = $request->validate(['direction' => 'required|in:up,down'])['direction'];

    $voter = $request->user(); // User or CustomerUser

    $existingVote = PostVote::where('post_id', $post->id)
        ->where('voter_type', get_class($voter))
        ->where('voter_id', $voter->id)
        ->first();

    DB::transaction(function () use ($existingVote, $post, $voter, $direction) {
        if ($existingVote) {
            if ($existingVote->direction === $direction) {
                // Toggle off
                $existingVote->delete();
                $post->decrement($direction === 'up' ? 'upvotes_count' : 'downvotes_count');
            } else {
                // Switch direction
                $oldColumn = $existingVote->direction === 'up' ? 'upvotes_count' : 'downvotes_count';
                $newColumn = $direction === 'up' ? 'upvotes_count' : 'downvotes_count';
                $existingVote->update(['direction' => $direction]);
                $post->decrement($oldColumn);
                $post->increment($newColumn);
            }
        } else {
            PostVote::create([
                'post_id'    => $post->id,
                'voter_type' => get_class($voter),
                'voter_id'   => $voter->id,
                'direction'  => $direction,
                'organization_id' => $post->organization_id,
            ]);
            $post->increment($direction === 'up' ? 'upvotes_count' : 'downvotes_count');
        }

        $post->recomputePriorityScore();
    });

    WebhookDispatcherService::dispatch('post.voted', $post);

    return response()->json([
        'upvotes_count'   => $post->fresh()->upvotes_count,
        'downvotes_count' => $post->fresh()->downvotes_count,
        'user_vote'       => PostVote::where('post_id', $post->id)
                                ->where('voter_type', get_class($voter))
                                ->where('voter_id', $voter->id)
                                ->value('direction'),
    ]);
}
```

```php
// PostMergeController@store
public function store(MergePostRequest $request): RedirectResponse
{
    $this->authorize('update', Post::find($request->parent_post_id));

    DB::transaction(function () use ($request) {
        $parent = Post::findOrFail($request->parent_post_id);
        $child  = Post::findOrFail($request->child_post_id);

        // Re-parent votes
        PostVote::where('post_id', $child->id)->update(['post_id' => $parent->id]);

        // Re-parent comments
        PostComment::where('post_id', $child->id)->update(['post_id' => $parent->id]);

        // Re-parent subscribers
        PostSubscriber::where('post_id', $child->id)->update(['post_id' => $parent->id]);

        // Update vote counts on parent
        $parent->upvotes_count   = $parent->votes()->where('direction', 'up')->count();
        $parent->downvotes_count = $parent->votes()->where('direction', 'down')->count();
        $parent->save();

        // Record merge
        PostMerge::create([
            'parent_post_id' => $parent->id,
            'child_post_id'  => $child->id,
            'merged_by_id'   => auth()->id(),
            'merged_at'      => now(),
        ]);

        // Mark child as merged
        $child->update(['merged_into_id' => $parent->id, 'is_hidden' => true]);
    });

    return back()->with('success', 'Posts merged successfully.');
}
```

### 13.2 — KbSearchService (Semantic + Keyword Blend)

```php
class KbSearchService
{
    public function search(string $query, string $orgId, int $limit = 10): Collection
    {
        // 1. Keyword search via Scout
        $keywordResults = KbArticle::search($query)
            ->where('organization_id', $orgId)
            ->get()
            ->keyBy('id');

        // 2. Semantic search via pgvector
        $queryEmbedding = $this->embeddingService->embed($query);
        $semanticIds = DB::select("
            SELECT kb_article_id, 1 - (embedding <=> ?) AS similarity
            FROM kb_article_embeddings
            WHERE organization_id = ?
            ORDER BY embedding <=> ?
            LIMIT ?
        ", [$queryEmbedding, $orgId, $queryEmbedding, $limit * 2]);

        // 3. Blend scores (0.4 keyword + 0.6 semantic)
        $semanticMap = collect($semanticIds)->keyBy('kb_article_id');
        $allIds = $keywordResults->keys()->merge($semanticMap->keys())->unique();

        return KbArticle::whereIn('id', $allIds)
            ->with('collection')
            ->get()
            ->sortByDesc(function ($article) use ($keywordResults, $semanticMap) {
                $keywordScore  = $keywordResults->has($article->id) ? 0.4 : 0;
                $semanticScore = ($semanticMap[$article->id]?->similarity ?? 0) * 0.6;
                return $keywordScore + $semanticScore;
            })
            ->take($limit)
            ->values();
    }
}
```

```typescript
// composables/useFormLogic.ts
export function useFormLogic(
  fields: FormField[],
  answers: Record<string, any>,
) {
  const visibleFields = computed(() => {
    return fields.filter((field) => {
      if (!field.logic || field.logic.length === 0) return true;
      return field.logic.every((rule) => {
        const answer = answers[rule.fieldId];
        switch (rule.operator) {
          case "equals":
            return answer == rule.value;
          case "not_equals":
            return answer != rule.value;
          case "contains":
            return String(answer).includes(rule.value);
          case "is_filled":
            return !!answer;
          case "is_empty":
            return !answer;
          default:
            return true;
        }
      });
    });
  });
  return { visibleFields };
}
```

### 16.2 — ProcessPostAIJob

```php
class ProcessPostAIJob implements ShouldQueue
{
    public int $tries = 3;
    public int $timeout = 120;
    public array $backoff = [30, 120, 300];

    public function handle(EmbeddingService $embeddings, AiService $ai): void
    {
        // 1. Generate embedding
        $vector = $embeddings->embed($this->post->title . ' ' . $this->post->content);

        DB::table('post_embeddings')->upsert([
            'post_id'         => $this->post->id,
            'organization_id' => $this->post->organization_id,
            'embedding'       => $vector,
        ], ['post_id']);

        // 2. Find duplicates
        $duplicates = DB::select("
            SELECT pe.post_id, 1 - (pe.embedding <=> ?) AS similarity
            FROM post_embeddings pe
            WHERE pe.organization_id = ? AND pe.post_id != ?
            ORDER BY pe.embedding <=> ?
            LIMIT 5
        ", [$vector, $this->post->organization_id, $this->post->id, $vector]);

        $duplicates = array_filter($duplicates, fn($d) => $d->similarity > 0.85);

        if (!empty($duplicates)) {
            $this->post->update(['ai_duplicate_suggestions' => array_column($duplicates, 'post_id')]);
        }

        // 3. Sentiment analysis
        $result = $ai->classifySentiment($this->post->title . ' ' . $this->post->content);
        $this->post->update([
            'sentiment'       => $result['sentiment'],
            'sentiment_score' => $result['score'],
        ]);

        // 4. Auto-tag
        $tags = $ai->suggestTags($this->post->title, $this->post->board->tags->pluck('name')->toArray());
        if (!empty($tags)) {
            $tagIds = PostTag::whereIn('name', $tags)
                ->where('organization_id', $this->post->organization_id)
                ->pluck('id');
            $this->post->tags()->syncWithoutDetaching($tagIds);
        }
    }
}
```

### 16.4 — Theme Clustering (Scheduled Command)

```php
// app/Console/Commands/RecomputeThemes.php
// Schedule: Schedule::command('ai:recompute-themes')->daily()
class RecomputeThemes extends Command
{
    public function handle(AiService $ai): void
    {
        Organization::all()->each(function ($org) use ($ai) {
            // Get all post embeddings from last 90 days
            $embeddings = DB::table('post_embeddings')
                ->join('posts', 'post_embeddings.post_id', '=', 'posts.id')
                ->where('post_embeddings.organization_id', $org->id)
                ->where('posts.created_at', '>=', now()->subDays(90))
                ->select('post_embeddings.post_id', DB::raw('embedding::text as embedding'))
                ->get();

            if ($embeddings->count() < 5) return;

            // Simple k-means via pgvector clustering (using DB query grouping)
            // Get cluster representatives using cosine distance to centroid
            $k = min(8, (int)($embeddings->count() / 5));

            // Use pgvector's approximate nearest neighbor to find cluster seeds
            // Then for each cluster, find top 5 nearest posts and send titles to GPT

            // For each cluster of post IDs:
            foreach ($this->computeClusters($embeddings, $k) as $cluster) {
                $postTitles = Post::whereIn('id', $cluster)->pluck('title')->toArray();

                $theme = $ai->labelCluster($postTitles);

                AiTheme::updateOrCreate(
                    ['organization_id' => $org->id, 'name' => $theme['name']],
                    [
                        'description'            => $theme['description'],
                        'post_count'             => count($cluster),
                        'representative_post_ids' => array_slice($cluster, 0, 5),
                        'last_computed_at'        => now(),
                    ]
                );
            }
        });
    }
}
```

### 19.2 — DeliverWebhookJob

```php
class DeliverWebhookJob implements ShouldQueue
{
    public int $tries = 3;
    public array $backoff = [5, 30, 300]; // seconds

    public function handle(): void
    {
        $payload = json_encode([
            'event'           => $this->event,
            'organization_id' => $this->model->organization_id,
            'timestamp'       => now()->toIso8601String(),
            'data'            => (new PostResource($this->model))->toArray(request()),
        ]);

        $signature = 'sha256=' . hash_hmac('sha256', $payload, $this->webhook->secret_hash);

        $response = Http::withHeaders([
            'Content-Type'        => 'application/json',
            'X-FeedbackOS-Event'  => $this->event,
            'X-Signature-256'     => $signature,
        ])->timeout(10)->post($this->webhook->url, json_decode($payload, true));

        WebhookDelivery::create([
            'webhook_id'        => $this->webhook->id,
            'event_type'        => $this->event,
            'payload'           => json_decode($payload, true),
            'status'            => $response->successful() ? 'success' : 'failed',
            'response_code'     => $response->status(),
            'response_body'     => mb_substr($response->body(), 0, 1000),
            'attempts'          => $this->attempts(),
            'last_attempted_at' => now(),
        ]);

        if (!$response->successful()) {
            throw new \RuntimeException("Webhook delivery failed: HTTP {$response->status()}");
        }
    }
}
```

### 24.4 — Custom Domain SSL Flow

1. Admin submits domain via `POST /settings/custom-domains`
2. Controller creates `CustomDomain` record and dispatches `ResolveCustomDomainJob`
3. Job: verify DNS TXT record (`_feedbackos-verify.{domain}` = `{verification_token}`)
4. On success: update `verified_at`, set `ssl_status = pending`
5. cert-manager `Certificate` resource is created via Kubernetes API
6. Let's Encrypt issues cert → ingress updated
7. `ssl_status` set to `active`
8. `ResolveOrganization` middleware now resolves org from this domain

## 27. Agent Rules & Conventions

### Naming Conventions

| Type            | Convention              | Example                    |
| --------------- | ----------------------- | -------------------------- |
| PHP Classes     | PascalCase              | `PostMergeController`      |
| PHP Methods     | camelCase               | `recomputePriorityScore()` |
| DB Tables       | snake_case plural       | `post_subscribers`         |
| DB Columns      | snake_case              | `organization_id`          |
| Vue Components  | PascalCase              | `PostDetailCard.vue`       |
| Vue Composables | camelCase, `use` prefix | `useFormLogic.ts`          |
| Inertia Pages   | PascalCase in folder    | `pages/Boards/Index.vue`   |
| Routes (named)  | dot-separated           | `boards.posts.store`       |
| Jobs            | Verb + Noun + Job       | `ProcessPostAIJob`         |
| Events          | Noun + PastVerb         | `PostStatusChanged`        |
| Policies        | Model + Policy          | `PostPolicy`               |

### Agent Rules (Follow Without Exception)

1. **Never skip migrations.** Every model must have a migration. Every column must be migrated before use.
2. **All tenant models use `BelongsToOrganization` trait.** No exceptions. Check every new model.
3. **All AI calls go through jobs.** Never call OpenAI from a controller directly (except the SSE stream endpoint).
4. **All integration credentials are encrypted.** Use `Crypt::encrypt()` on store, `Crypt::decrypt()` on read.
5. **All user-input content stored as Tiptap JSON.** Never store raw HTML from the frontend.
6. **Always use Form Request classes.** No `$request->validate()` in controllers directly.
7. **Always use Policies.** No role checks in controllers — use `$this->authorize()`.
8. **Ziggy for all route references in Vue.** Never hardcode `/boards/123/posts` — use `route('boards.posts.store', {board: id})`.
9. **Test tenant isolation.** After every new resource, add a test confirming org A cannot access org B data.
10. **Queue jobs for anything over 200ms.** If an operation takes time (AI, email, webhook, external API), queue it.
11. **Never store API keys in code.** All secrets come from `.env` via `config()` calls.
12. **pgvector columns use raw SQL.** Do not try to use Blueprint methods for `vector` columns — use `DB::statement()`.
13. **Inertia for admin pages. API routes for widget and external consumers.** Keep these layers clean.
14. **Seed default statuses on every new org.** Use an `OrganizationObserver::created()` to seed post statuses and a default board.
15. **All public-facing pages must work without auth.** Test every public route with an unauthenticated browser session.

### Error Handling

- All jobs must implement `failed(Throwable $e)` method to log failure and update `ai_analysis_jobs.status` to `failed`.
- All controllers must return consistent JSON error responses for API routes (use `ApiResponse` helper class).
- Use Laravel's exception handler to return Inertia error pages for web routes.
- Log all webhook delivery failures to `webhook_deliveries` table (even on job failure).

### Performance Rules

- **Eager load always.** No N+1 queries. Use `with()` in every controller that returns collections.
- **Paginate all lists.** Use `paginate(25)` for all list endpoints. Never `->get()` on unbounded collections.
- **Cache expensive queries.** Use `Cache::remember('key', 3600, fn() => ...)` for analytics aggregations.
- **Scout indexes on publish only.** Do not call `$model->searchable()` in every update — only on publish.
- **pgvector IVFFlat index.** Always create the IVFFlat index after inserting more than 1000 embeddings: `REINDEX INDEX CONCURRENTLY`.
